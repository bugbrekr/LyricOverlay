# LyricOverlay
View synced lyrics of any song on a floating window.

![Screenshot_20250717_130234](https://github.com/user-attachments/assets/76172d26-8157-415c-9404-60b622d10c4a)

## Requirements
- Python >= 3.10
- Required packages: \
  On Ubuntu/Debian:
  ```
  sudo apt install libglib2.0-dev libcairo2-dev libgirepository1.0-dev libgirepository-2.0-dev
  ```
- `pip install -r requirements.txt`
